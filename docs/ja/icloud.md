# iCloud Drive の保管庫

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/icloud.md)

iCloud Drive の保管庫も使えますが、対応は試験的です。確かめたのは、iPhone 1台、Wi-Fi、小さな保管庫だけです。

選べるなら、「このiPhone内」の保管庫の方が簡単です。

## 頼る前に

**最初の同期は、すべてのファイルを読みます。** 「最初からやり直す」の後の同期も、同じです。

- iCloud は、デバイスから外したファイルを、読むために戻します。
- そのため、保管庫全体の分の空きと通信が要ります。
- 戻せないファイルが1つでもある間は、その同期は終わらず、何もアップロードしません。

**GitHub にはつながり、iCloud にはつながらない時**は、デバイスに無いファイルを読めません。たとえば、モバイルデータ通信で iCloud Drive をオフにしている時です。

- Sync Evo は、そのファイルに手を付けません。
- 同期の結果で、そのことを知らせます。
- 次の時に、もう一度試します。

**iCloud がファイルの2つのバージョンを見つけた時**は、両方を残して、片方を `<name> 2.md` という名前にすることがあります。Sync Evo は、それを新しいファイルとして送ります。

## Mac で iCloud の保管庫を git の作業ツリーにしない

保管庫が iCloud にあると、Mac と iPhone は1つのフォルダを共有します。

- Mac の git は、iPhone の Sync Evo が送った物を知りません。
- 次の pull が止まります。
- iPhone の Sync Evo が、保管庫に `.git` があると知らせたら、これが起きています。

## 同じ iCloud の保管庫を2台のデバイスで同期しない

同じ iCloud の保管庫を、2台のデバイスの Sync Evo で同期しないでください。iCloud が、すでにすべての変更をデバイスの間で運んでいます。同じ変更を2回同期すると、重複が残ることがあります。
