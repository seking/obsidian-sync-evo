# セットアップ

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/setup.md)

## 要る物

- Obsidian 1.11.4 以降。
- GitHub のアカウントとリポジトリ、Dropbox のアカウント、または Google アカウント。Google Drive には、Sync Evo 0.5.0 以降が要ります。0.5.0 は、まだ公開していません。今試すには、BRAT でベータを入れます。
- 開発者のアカウントは要りません。
- Sync Evo は、今はどのサービスでも無料です。Dropbox と Google Drive では、いずれ、3か月の無料の後に有料になる可能性があり、その時は始める前に知らせます。[料金](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#料金)を見てください。

## インストール

Sync Evo は、まだコミュニティプラグインの一覧にありません。載るまでは、[BRAT](https://github.com/TfTHacker/obsidian42-brat) で `seking/obsidian-sync-evo` からインストールします。

1. 設定 → コミュニティプラグインで、**制限モード**がオンならオフにします。**閲覧**を押し、**BRAT**を検索して、インストールし、有効にします。
2. 設定 → BRAT で**Add beta plugin**を押し、`https://github.com/seking/obsidian-sync-evo` を入力します。バージョンは最新のままにして、追加します。
3. 設定 → コミュニティプラグインで、**Sync Evo**を有効にします。更新は BRAT が行います。

## 始める前に

- **1台のデバイスでは、Git か Sync Evo のどちらかだけを使ってください。** パソコンは Git、スマートフォンは Sync Evo のように、1つのリポジトリを分けて使えます。デバイスを Git から Sync Evo に移すには、[デバイスを Git から Sync Evo に移す](faq.md#デバイスを-git-から-sync-evo-に移す)を見てください。
- **iCloud Drive の保管庫への対応は、試験的です。** 同じ iCloud の保管庫を、2台のデバイスの Sync Evo で同期しないでください。Mac で、git の作業ツリーにしないでください。[詳細](icloud.md)

## GitHub

1. 保管庫のリポジトリがまだ無ければ、GitHub で空のプライベートリポジトリを作ります。README などのファイルは足さないでください。最初のアップロードで中身が入ります。
2. [トークンを作るページ](https://github.com/settings/personal-access-tokens/new?name=Sync+Evo&description=Obsidian+Sync+Evo&expires_in=90&contents=write)を開きます。名前、期限、**Contents: Read and write** は入力済みです。
   - 「Repository access」で **Only select repositories** を選び、保管庫のリポジトリを選びます。リポジトリは、リンクでは選べません。
   - サブモジュールや `.github/workflows/` の下のファイルがある時は、トークンにもっと権限が要ります。[トークンの権限](settings.md#トークンの権限)を見てください。
3. Obsidian で、設定 → コミュニティプラグイン → Sync Evo を開きます。「接続」で、次を入力します。
   - **リポジトリ**：`owner/name`、またはブラウザから貼ったアドレス。
   - **ブランチ**：同期するブランチ。新しい空のリポジトリなら、`main`（または GitHub が表示する既定のブランチの名前）を入力します。最初のアップロードで作られます。すでにあるリポジトリでは、Sync Evo はブランチを作りません。
   - **トークン**：トークンを入れたシークレットを選びます。まだ無ければ、シークレットを作り（名前は `Sync Evo` など）、値にトークンを貼ります。トークンは Obsidian のキーチェーンに保存され、保管庫には入りません。[トークン](settings.md#トークン)を見てください。
   - **デバイス名**：コミットメッセージと、競合ファイルの名前に使われます。
4. 「接続のテスト」の**テスト**を押します。トークンでリポジトリとブランチにつながるかが分かります。
5. 同期します。画面の端に並ぶアイコンの列（リボン）から、円を描く2本の矢印のアイコン（**同期する**）をタップするか、コマンドパレットで**Sync Evo: 同期する**を実行します。
   - 最初のダウンロードでは、保管庫のファイルがリポジトリの物と違う時に、確かめます。
   - 空のリポジトリへの最初のアップロードでは、確かめず、アップロードした物を結果で知らせます。リポジトリが公開されている時は、誰でも見られるので、先に確かめます。
   - すでにファイルがあるリポジトリへの最初のアップロードでは、アップロードする物を示して、確かめます。

## Dropbox

1. Obsidian で、設定 → コミュニティプラグイン → Sync Evo を開きます。「接続」で、**サービス**を**Dropbox**にします。**フォルダ**（最初は保管庫の名前）と**デバイス名**（競合ファイルの名前に使います）を確かめます。
2. **接続する**を押し、求められたら Dropbox にログインして、**許可**を押します。ブラウザから Obsidian に戻ります。
3. GitHub の手順 4 と 5 と同じように、**テスト**を押し、**同期する**を実行します。

Sync Evo が使えるのは、Dropbox の中の Sync Evo 自身のフォルダ `Apps/Sync Evo/` だけです。削除したファイルは、しばらく Dropbox のバージョン履歴に残ります。詳しく：[Dropbox](dropbox.md)。

## Google Drive

1. Obsidian で、設定 → コミュニティプラグイン → Sync Evo を開きます。「接続」で、**サービス**を**Google Drive**にします。**フォルダ**（最初は保管庫の名前）と**デバイス名**（競合ファイルの名前に使います）を確かめます。
2. **接続する**を押します。Sync Evo がウィンドウにコードを表示し、コピーします。ウィンドウの**ブラウザで開く**を押します。ブラウザで `google.com/device` が開き、コードもまたコピーされます。
3. ブラウザでコードを貼り、Google アカウントを選んで、Sync Evo を許可します。終わったら Obsidian に戻ります。コードのウィンドウはひとりでに閉じ、設定画面に、接続したアカウントが出ます。
4. GitHub の手順 4 と 5 と同じように、**テスト**を押し、**同期する**を実行します。

どのデバイスでも、同じ Google アカウントに接続し、同じフォルダの名前にします。Sync Evo は、保管庫をマイドライブの `Sync Evo/<folder>` に置き、そこで自分が作ったファイルだけを見ます。Sync Evo が削除したファイルは、Drive のゴミ箱に入ります。詳しく：[Google Drive](google-drive.md)。
