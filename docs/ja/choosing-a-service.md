# GitHub・Dropbox・Google Drive のどれか

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/choosing-a-service.md)

## どれを選ぶか

- **GitHub のアカウントがある、パソコンで Git を使う、ノートの履歴をすべて残したい**：GitHub。
- **どれでもない**：保管庫が 2 GB までなら Dropbox。2台のデバイスで変えたノートを統合できます。超えるなら Google Drive（Google アカウントの空きの分まで）。
- **Dropbox か Google Drive をもう使っている**：それでも構いません。Dropbox の有料プランなら、2 GB を超えても入ります。

Dropbox と Google Drive は、ログインするだけで使えます。リポジトリやトークンは要りません。料金は[料金](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#料金)を見てください。

## 並べて比べる

| | GitHub | Dropbox | Google Drive |
| --- | --- | --- | --- |
| Sync Evo の料金 | 今は無料 | 今は無料。いずれ、3か月の無料の後にライセンスキーが要るようになる可能性があります（月 $3・年 $24・買い切り $49。1つのキーで両方を使えます） | Dropbox と同じ |
| セットアップ | リポジトリとトークンを作り、両方を入力します | **接続する**を押し、Sync Evo を許可します | **接続する**を押し、**ブラウザで開く**を押して、コードを貼り、Sync Evo を許可します |
| その後の手入れ | トークンには期限があります（README のリンクで作ると90日）。切れたら新しく作ります | 要りません。ただし、Dropbox で接続が外されたら、接続し直します | 要りません。ただし、Google アカウントで接続が外された時や、アカウントの接続が100を超えて古い物が切れた時は、接続し直します |
| 無料の容量 | プライベートリポジトリは無料です。GitHub は1つを 1 GB 未満にするよう勧めていて、履歴の分だけ大きくなります | 無料プランで 2 GB | 無料の Google アカウントで 15 GB。Gmail や Google フォトと共有です |
| 履歴 | アップロードのたびにコミットになります。前のバージョンは、すべて履歴に残ります | 前のバージョンと削除したファイルは、しばらく Dropbox のバージョン履歴に残ります（無料プランで30日） | Sync Evo が削除したファイルは、Drive のゴミ箱に30日入ります。上書きされたバージョンは、Drive のそのファイルのバージョン履歴に残ります |
| 2台のデバイスで変えたノートの統合 | いつでもできます | 前回の同期の時のバージョンが、Dropbox の最新の100バージョンの中にあれば、できます。無ければ、両方のバージョンを残します | しません。両方のバージョンを残します |
| Sync Evo の外で足したファイル | 同期します（Git で push した物など） | まだ試していません | 見えません。Sync Evo から見えるのは、Sync Evo が作ったファイルだけです |
| Android での、大きな保管庫の最初のダウンロード | 約5,000ファイルを超えると、GitHub の1時間ごとの上限を待つため、1時間以上かかることがあります | GitHub のような1時間ごとの上限はありません。待つのは、Dropbox が待つよう求めた時だけです。大きな保管庫では、まだ試していません | GitHub のような1時間ごとの上限はありません。待つのは、Google が待つよう求めた時だけです。大きな保管庫では、まだ試していません |
| パソコンの Git | 同じリポジトリで使えます | 使えません | 使えません |
| 試した環境 | iPhone と Mac。基本の同期は Android・iPad・Windows でも。Linux ではまだ | Android と iPhone。パソコンではまだ | Android と iPhone。パソコンではまだ |

ファイルの大きさの上限は、3つとも同じです（38 MB）。どれも、デバイスに GitHub・Dropbox・Google Drive のアプリは要りません。どれでも、大文字と小文字だけが違う2つのパスを、Sync Evo は同期しません。

後から変えられます。サービスを変えると、最初のダウンロードと同じように、同期を最初からやり直します。保管庫のファイルは削除しません。新しいサービスの物と中身が違うファイルは、新しいサービスの物に置き換わり、保管庫の物は競合ファイルとして残ります。

詳しく：[Dropbox](dropbox.md)、[Google Drive](google-drive.md)、[制限](limits.md)。
