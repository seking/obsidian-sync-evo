# 設定

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/settings.md)

## 接続

GitHub では、

- **リポジトリ**：`owner/name` の形か、ブラウザから貼ったアドレス。
- **ブランチ**：同期するブランチ。Sync Evo はブランチを作りません。
- **トークン**：トークンを入れたシークレット。[トークン](#トークン)を見てください。
- **デバイス名**：コミットメッセージと、競合ファイルの名前に使われます。

Dropbox は [Dropbox](dropbox.md)、Google Drive は [Google Drive](google-drive.md) を見てください。

Dropbox と Google Drive では、有料化を始めた後は、**ライセンスキー**もあります。[ライセンスキー](#ライセンスキー)を見てください。

### トークン

- トークンは Obsidian のキーチェーンに保存され、保管庫のファイルには書かれません。
- 設定に入るのは、保存した時の名前だけです。
- **トークン**の下のリンクで、トークンを作る GitHub のページが開きます。名前、期限（90日）、**Contents: Read and write** は入力済みです。リポジトリは、そのページで選びます。
- iPhone と Android では、デバイスのどの保管庫からも、同じシークレットを選べます。
- Windows と Mac では、保管庫ごとに別です。保管庫の一覧から外して開き直した保管庫では、トークンをまた求められます。

### トークンの権限

トークンは、[fine-grained personal access token](https://github.com/settings/personal-access-tokens) です。要るのは、

- 保管庫のリポジトリだけへのアクセス、
- リポジトリの権限 **Contents: Read and write**

です。

保管庫にサブモジュールがある時は、

- そのリポジトリにも、トークンからアクセスできるようにします。
- それらには **Contents: Read-only** で足ります。ただし、1つのトークンの権限は、すべてのリポジトリで共通です。

保管庫に `.github/workflows/` の下のファイルがあり、それをデバイスで変える時は、トークンに **Workflows: Read and write** も要ります。

### ライセンスキー

Dropbox と Google Drive での Sync Evo は、今は無料です。いずれ有料になる可能性があり、その時は、3か月は無料で、その後はライセンスキーが要ります。1つのキーで両方を使えます。GitHub は今は無料です。[料金](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#料金)を見てください。

有料化は、まだ始めていません。始めるまでは、設定に**ライセンスキー**はありません。

始めた後は、Dropbox と Google Drive で、「接続」の中に**ライセンスキー**が出ます。

- キーは、デバイスごとに入れます。欄から離れた時に読み取ります。
- 1つのキーは、どの保管庫で入れても、このデバイスの分です。アプリのローカルストレージに保存され、保管庫のファイルには書かれません。
- Sync Evo は、キーを売っている Dodo Payments に問い合わせて、キーを確かめます。送るのは、キーと、このデバイスのアクティベーションの名前としての**デバイス名**です。保管庫の物は送りません。[通信とプライバシー](network.md#ライセンスキー)を見てください。
- 1つのキーは、5台までのデバイスで使えます。欄を空にすると、このデバイスからキーを外し、Dodo でのアクティベーションを終えます。空いた分は、ほかのデバイスで使えます。デバイスがもう無い時は、Dodo Payments の[請求ポータル](https://customer.dodopayments.com/login/bus_0NpvnyuwMvGA62iaE3swK)でアクティベーションを外すか、contact@gyap.jp にご連絡ください。
- 欄の下に、このデバイスの状態を表示します。
  - 「このアカウントでは、… まで無料です。」：無料の期間の間（いつ始まったかを Sync Evo が知るまでは「このアカウントでは、3か月は無料です。終わる日は、次の同期の後に表示します。」）。
  - 「無料の期間は … に終わりました。… までは、ダウンロードだけを行います。」：その後の30日。
  - 「無料の期間は … に終わりました。… との同期を止めています。」：その30日の後。
  - 「このデバイスでキーを使っています。」
  - 「… からキーを確かめられていません。… までは使え、その間にまた確かめます。」：Dodo につながらなかった時。使えていたキーは、14日のあいだ使えます。
  - 「キーを確かめられませんでした。…」：Dodo につながらず、その14日の間にキーが使えたことも無い時。
  - 「このキーは使えません。」：返金された、取り消された、期限が終わった、または Sync Evo のキーでない時。
- 自分の Google のクライアントを使う時は、キーは要りません。[自分の Google のクライアント](#自分の-google-のクライアント)を見てください。

## 自分の Google のクライアント

Google Drive の時に出ます。開くまでは閉じています。慣れた人向けで、Sync Evo の Google のクライアントが使えなくなった時のための物です。

- **クライアント ID** と **クライアント シークレット**：自分の Google Cloud のプロジェクトで作った、種類が「テレビと入力が限られたデバイス」の OAuth クライアントの物です。
- クライアントを変えると、接続し直すよう求められます。別のプロジェクトのクライアントでは、保管庫を新しいフォルダにアップロードし直し、古いフォルダは Google Drive に残ります。
- Sync Evo のクライアントに戻すには、ID を空にします。

要る物と、変わること：[自分の Google のクライアント](google-drive.md#自分の-google-のクライアント)を見てください。

## 同期しない物

同期しない物は、2か所で決めます。

- 保管庫のルートの `.gitignore`。全デバイスと、パソコンの git に効きます。
- 各デバイスの設定。そのデバイスだけに効きます。

設定画面が、どちらも書きます。

### 同期しない物（全デバイス）

ここの設定は、保管庫のルートの `.gitignore` の、`# >>> Sync Evo` と `# <<< Sync Evo` で始まる2行の間に書きます。全デバイスと、パソコンの git に同じように効きます。

- **除外フォルダ**：同期しないフォルダ。保管庫のルートからのパスで書きます。
- **保管庫の設定を同期**：設定フォルダ（`.obsidian/`）のどの項目を同期するか。項目の名前は、Obsidian Sync と同じです。

### 同期しない物（このデバイスのみ）

ここの設定は、デバイスのほかの設定と一緒に保存します。ほかのデバイスにも git にも届きません。このまとまりは、開くまで閉じていて、名前の横に、何を除外しているかを表示します。

- **ファイルの種類**：画像、音声、動画、PDF、その他のすべての種類。ノート、キャンバス、ベースは、常に同期します。
- **除外フォルダ**：上と同じ物を、このデバイスだけに。

### 規則を直接書く（.gitignore）

自分の規則を書くために、ファイル全体を表示します。規則は、Sync Evo が管理する行の外に書きます。

### 初期設定で除外している物

- ゴミ箱
- 画面の配置
- Sync Evo 自身のフォルダ
- OS が残すファイル

### `.gitignore` の規則と git の違い

`.gitignore` の規則は、git と同じように読みますが、効き方が違います。

- 除外した物は、リポジトリにすでにあっても、同期しません。
- git は、すでに管理しているファイルを、管理し続けます。

そのため、`.obsidian/plugins/` がリポジトリにあり、それを `.gitignore` に足すと、Sync Evo のデバイスは同期をやめます。パソコンの git は、アップロードし続けます。

効くのは、ルートの `.gitignore` だけです。[制限](limits.md)を見てください。

### 除外した時に起きること

- 除外しても、デバイスでも GitHub・Dropbox・Google Drive でも、何も削除しません。
- 除外した物は、GitHub・Dropbox・Google Drive にすでにあっても、同期しません。
- アップロードも、ダウンロードもしません。
- どちらかで削除しても、もう片方には反映しません。

**除外していて、GitHub に残っているファイル**（または Dropbox、Google Drive）には、そこにあり、全デバイスで除外しているファイルが並びます。**GitHub から削除**（または Dropbox、Google Drive）で、これを片付けます。

- GitHub・Dropbox・Google Drive から削除します。
- Sync Evo のデバイスには、どれにも残します。
- パソコンの git では、次の `git pull` で作業ツリーから削除されます。

除外している間に削除した物は、除外をやめても、もう片方では削除されません。

- デバイスで削除したファイルは、またダウンロードされます。
- GitHub・Dropbox・Google Drive から削除したファイルは、またアップロードされます。

そのため、パソコンの git でわざと削除したファイルが、それを除外していたデバイスから、またアップロードされることがあります。

### インストールされているコミュニティプラグイン

> [!WARNING]
> この項目を入にすると、ほかのデバイスから来たコードが動きます。

- 入にすると、ほかのプラグインのコードを同期します。
- その `data.json` も同期します。トークンなどが入っていることがあります。
- ほかのデバイスから来たプラグインのコードが、このデバイスで動きます。
- 信頼できるデバイスとリポジトリでだけ、入にしてください。
- Sync Evo は、自身のフォルダを同期しません。

### アクティブなコミュニティプラグインのリスト

> [!WARNING]
> このリストを同期している間は、全デバイスで Sync Evo を有効にしておいてください。

Sync Evo が有効でないデバイスがあると、そのデバイスが送るリストによって、ほかのデバイスでも次の起動で Sync Evo が無効になります。そこで同期が止まります。

## 同期のしかた

ここの設定は、デバイスごとに保存します。自動同期の3つの切り替えは、入にするまで切です。

- **起動時に同期する**：Obsidian を起動した時と、ほかのアプリから戻った時に同期します。直前の同期を始めてから5分たっていない時は、同期しません。
- **一定間隔で同期する**：Obsidian が前に出ている間、直前の同期を始めてから間隔（分）がたつたびに同期します。同期に失敗すると、次は2倍待ちます。最長で1時間です。
- **自動同期でこのデバイスの変更もアップロードする**：
  - 切の時、自動同期はダウンロードだけを行います。デバイスで編集した内容は、手動で同期した時にアップロードされます。
  - 入の時、間隔は5分以上になります。GitHub では、アップロードのたびにコミットになるためです。Dropbox では、そうしないと、書きかけのノートが何度もアップロードされるためです。
  - Google Drive では、どちらでも間隔は5分以上です。確かめるたびに、Sync Evo の利用者全員で分け合う上限に数えられるためです（[Google Drive](google-drive.md#google-の制限)を見てください）。
- **競合した時**：「自動で統合」（初期設定）か「競合ファイルを作成」。[両方で変わったファイル](syncing.md#両方で変わったファイル)を見てください。Google Drive では、いつも競合ファイルを作ります。

自動同期の動き方は、[同期する時](syncing.md#同期する時)にあります。
