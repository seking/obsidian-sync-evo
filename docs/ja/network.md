# 通信とプライバシー

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/network.md)

Sync Evo が通信するのは、使った時か、自動同期を有効にしている時だけです。ほかへは何も送りません。利用状況は集めません。開発者のサーバーもありません。詳しくは、[Sync Evo が通信する時](#sync-evo-が通信する時)にあります。

Sync Evo のプライバシーポリシーは、[gyap.jp/sync-evo/privacy](https://gyap.jp/sync-evo/privacy) にあります。

## 一覧

**GitHub**（トークンと、リポジトリとブランチの名前を付けて）

| 操作 | ホスト | 送る物 | 目的 |
| --- | --- | --- | --- |
| 接続のテスト | `api.github.com` | リポジトリとブランチの問い合わせ | トークンでつながるかを確かめるため |
| ダウンロード | `api.github.com`、`codeload.github.com` | ファイルの一覧と中身の問い合わせ。保管庫の物は送りません。 | 新しいファイルと変わったファイルを受け取るため |
| アップロード | `api.github.com` | 足したファイルと変えたファイル、足した・変えた・削除したファイルのパス、コミット | 変更を送るため |
| GitHub から削除 | `api.github.com` | 削除するパス、`.gitignore`、コミット | 除外しているファイルをリポジトリから削除するため |

**Dropbox**（Dropbox がこのデバイスに出したトークンと、保管庫のフォルダのパスを付けて）

| 操作 | ホスト | 送る物 | 目的 |
| --- | --- | --- | --- |
| 接続する、接続を解除 | `www.dropbox.com`、`api.dropboxapi.com` | ブラウザでのログイン。その後、コード（接続する）かトークン（接続を解除） | このデバイスを接続するため、また接続を忘れさせるため |
| 接続のテスト | `api.dropboxapi.com` | 保管庫のフォルダの問い合わせ | フォルダがあるかを確かめるため |
| ダウンロード | `api.dropboxapi.com`、`content.dropboxapi.com` | 変更、ファイルの中身、バージョンの問い合わせ | 新しいファイルと変わったファイルを受け取るため、また統合するため |
| アップロード | `api.dropboxapi.com`、`content.dropboxapi.com` | 足したファイルと変えたファイル、削除したファイルのパス | 変更を送るため |
| Dropbox から削除 | `api.dropboxapi.com`、`content.dropboxapi.com` | `.gitignore` と、削除するパス | 除外しているファイルを Dropbox から削除するため |

**Google Drive**（Google がこのデバイスに出したトークンと、保管庫のフォルダの名前を付けて）

| 操作 | ホスト | 送る物 | 目的 |
| --- | --- | --- | --- |
| 接続する | `oauth2.googleapis.com`、`www.googleapis.com` | コードの要求（設定画面を開いた時点で）、トークンの要求、その後にアカウントの問い合わせ | このデバイスを接続するため |
| 接続のテスト | `www.googleapis.com` | `Sync Evo` フォルダと保管庫のフォルダの問い合わせ | フォルダがあるかを確かめるため |
| ダウンロード | `www.googleapis.com` | 変更、ファイルの一覧、ファイルの中身の問い合わせ | 新しいファイルと変わったファイルを受け取るため |
| アップロード | `www.googleapis.com` | 足したファイルと変えたファイルとその名前、ゴミ箱に入れるファイル | 変更を送るため |
| Google Drive から削除 | `www.googleapis.com` | `.gitignore` と、ゴミ箱に入れるファイル | 除外しているファイルを Google Drive から削除するため |

**ライセンスキー**（有料化を始めた後、Dropbox か Google Drive で、キーを入れた時だけ）

| 操作 | ホスト | 送る物 | 目的 |
| --- | --- | --- | --- |
| キーを入れる、確かめる | `live.dodopayments.com` | キーと、デバイス名（初回）か、このデバイスのアクティベーションの ID（2回め以降）。保管庫の物も、Dropbox や Google のアカウントのことも送りません | このデバイスでキーをアクティベートするため、またキーがまだ使えるかを確かめるため |
| キーを空にする | `live.dodopayments.com` | キーと、このデバイスのアクティベーションの ID | このデバイスのアクティベーションを終えるため |

有料化は、まだ始めていません。始めるまでは、Sync Evo は Dodo Payments にまったく接続しません。

Sync Evo を許可するページ `www.google.com/device` は、ブラウザで開きます。Sync Evo 自身は、そこに接続しません。**接続を解除**は、何も送りません。

- GitHub のトークンは、Obsidian のキーチェーンに保存します。Sync Evo が Dropbox や Google Drive につながるための物は、アプリのローカルストレージに保存します。設定と、何を同期したかの記録は、デバイスの保管庫の外に置きます。Sync Evo は `data.json` を書きません。
- Sync Evo は、自身のフォルダを同期しません。

このページの残りで、すべての通信を詳しく示します。

## Sync Evo が通信する時

Sync Evo が通信するのは、次の時だけです。

- 設定で「テスト」を押した時。
- Sync Evo のコマンドを実行した時か、リボンの Sync Evo のボタンを押した時。
- 設定で、除外しているファイルを GitHub・Dropbox・Google Drive から削除した時。
- Dropbox で、「接続する」か「接続を解除」を押した時。
- Google Drive で、このデバイスが接続していない時に設定画面を開いた時（Sync Evo は「接続する」を押す前に、Google にコードを求めておきます）と、「接続する」を押した時。
- 有料化を始めた後、ライセンスキーを入れた時か空にした時。また、キーをまた確かめる時期に、Dropbox か Google Drive で同期した時か、設定画面を開いた時（[ライセンスキー](#ライセンスキー)を見てください）。

「同期のしかた」で自動同期を有効にしている時は、ひとりでに始めるダウンロードとアップロードでも通信します。問い合わせる物と送る物は、ダウンロードとアップロードと同じです。

ほかへは何も送りません。Sync Evo は利用状況を集めず、開発者のサーバーにも接続しません。

## GitHub

通信は、すべて GitHub（`api.github.com`）へ行きます。付けるのは、

- トークン、
- リポジトリとブランチの名前、またはサブモジュールが指すリポジトリの名前

です。

1種類の通信、下で述べる zip のダウンロードだけは、GitHub が別のホスト（`codeload.github.com`）へ転送します。

### 接続のテスト

- 入力したブランチを問い合わせます。
- ブランチが見つからない時は、リポジトリを問い合わせます。
- これで、トークンでつながるかが分かります。

### ダウンロード

ダウンロードは、保管庫の物を何も送りません。ファイルも、ファイルの名前も、中身もです。問い合わせるのは、

- ブランチ。ブランチが見つからない時は、リポジトリも（テストと同じ）。
- 最新のコミットのファイルの一覧。
- 新しいファイルと変わったファイルの、それぞれの中身。

です。

ほかに、

- **シンボリックリンク。** リンクは、保管庫に書き込みません。ダウンロードは、リンクがどこを指すかを読みます。新しいリンクか変わったリンク1つにつき、小さな問い合わせが1回です。
- **進んだブランチ。** 前回のダウンロードの後にブランチが動いた時は、新しいコミットが古いコミットの続きかを問い合わせます。
- **zip。** 新しいファイルと変わったファイルが1,000を超える時（大きなリポジトリの最初のダウンロードなど）は、ファイルごとに問い合わせる代わりに、そのコミットの zip を1回で求めます。これは、zip がデバイスに大きすぎないと見込める時だけです。Android では行いません。[制限](limits.md#1ファイルずつダウンロードする)を見てください。その後は、zip の中身が一覧と合わないファイルだけを問い合わせます。zip はメモリに置くだけで、保存しません。
- **サブモジュール。** リポジトリにサブモジュールがある時は、ダウンロードで `.gitmodules` を読みます。その後、各サブモジュールが指すリポジトリに、GitHub で同じトークンを使って、次を問い合わせます。
  - サブモジュールが指すコミットのファイルの一覧。
  - 新しいファイルと変わったファイルの中身（または、上と同じく、そのコミットの zip）。
  - 一覧が取れない時は、トークンでそのリポジトリがそもそも見えるか。

### アップロード

アップロードは、

1. ダウンロードと同じく、ブランチとファイルの一覧を問い合わせます。
2. 保管庫で足したファイルと変えたファイルの、それぞれの中身を送ります。
3. 足した・変えた・削除したファイルのパスを送ります。
4. デバイス名とそのパスをメッセージに入れたコミットを送ります。
5. ブランチを、そのコミットへ進めます。
6. 新しいコミットのファイルの一覧を問い合わせます。

ほかに、

- 前のアップロードができたかが分からない時は、先に、ブランチのコミットが、このデバイスが最後に同期したコミットの続きかを問い合わせます。
- まだコミットが無いリポジトリでは、既定のブランチを知るために、リポジトリを問い合わせます。`.gitignore` を、それだけのコミットとして先に送ります。
- 除外しているファイルは、送りません。

### GitHub からファイルを削除する

1. 先にダウンロードを行います。
2. ダウンロードと同じく、ブランチとファイルの一覧を問い合わせます。
3. リポジトリから削除するファイルのパスを送ります。
4. リポジトリの `.gitignore` がデバイスの物と違う時は、保管庫の `.gitignore` を送ります。
5. デバイス名とそのパスをメッセージに入れたコミットを送ります。
6. ブランチを、そのコミットへ進めます。

保管庫のほかの変更は、一緒に送りません。

## Dropbox

Dropbox では、同じ操作が、代わりに Dropbox（`api.dropboxapi.com` と `content.dropboxapi.com`）へ行きます。付けるのは、

- Dropbox がこのデバイスに出したトークン、
- 保管庫のフォルダのパス

です。

使えるのは、Sync Evo 自身のフォルダだけです。

### 接続と接続の解除

- **接続する**は、ブラウザで Dropbox のページ（`www.dropbox.com`）を開きます。
- 許可した後、Sync Evo は、Dropbox から戻ったコードをトークンに換えます。
- どのアカウントに接続したかを問い合わせます。
  - ID。同じアカウントへの接続し直しを、別のアカウントと見分けるためです。
  - メールアドレス。設定画面に表示するためです。
- トークンは、期限が切れると、Dropbox で新しくします。数時間ごとです。
- **接続を解除**は、トークンを忘れるよう Dropbox に伝えます。

### 接続のテスト

保管庫のフォルダがあるかを問い合わせます。

### ダウンロード

- 前回の同期の後に、フォルダで何が変わったかを問い合わせます（初回は、ファイルの一覧すべて）。
- 新しいファイルと変わったファイルの、それぞれの中身を問い合わせます。
- ファイルを統合するには、そのバージョンの一覧と、前回の同期の時のバージョンの中身を問い合わせます。

### アップロード

- 足したファイルと変えたファイルの、それぞれの中身とパスを送ります。
- 削除したファイルのパスを送ります。
- その後、フォルダで何が変わったかを、また問い合わせます。

### Dropbox からファイルを削除する

- Dropbox の `.gitignore` がデバイスの物と違う時は、保管庫の `.gitignore` を送ります。
- その後、削除するファイルのパスを送ります。

## Google Drive

Google Drive では、同じ操作が、代わりに Google（`oauth2.googleapis.com` と `www.googleapis.com`）へ行きます。付けるのは、

- Google がこのデバイスに出したトークン、
- 保管庫のフォルダの名前と、そのフォルダとファイルの ID

です。

Sync Evo が求めるのは、Sync Evo が自分で作ったファイルだけです（`drive.file` の権限）。Google Drive のほかの物は、何も使えません。

### 接続と接続の解除

- 設定画面が Google Drive を表示していて、このデバイスが接続していない時は、Sync Evo は Google にコードを求めます（`oauth2.googleapis.com`）。コードは、期限の間は持っておきます。
- **接続する**は、コードを表示して、コピーします。そのウィンドウの**ブラウザで開く**は、ブラウザで Google のページ（`www.google.com/device`）を開きます。そのページは、利用者と Google の間の物です。Sync Evo は、そこに接続しません。
- 許可する間、Sync Evo は数秒ごとに、許可されたかを Google に問い合わせます（`oauth2.googleapis.com`）。その後、トークンを受け取ります。
- どのアカウントに接続したかを問い合わせます（`www.googleapis.com`）。
  - ID。同じアカウントへの接続し直しを、別のアカウントと見分けるためです。
  - メールアドレス。設定画面に表示するためです。
- トークンは、期限が切れると、Google で新しくします。1時間ごとです。
- **接続を解除**は、何も送りません。このデバイスでだけ、トークンを忘れます。Google に伝えると、全デバイスの接続が切れるためです。全デバイスの接続を取り消す時は、Google アカウントの「サードパーティ製のアプリとサービス」から Sync Evo を外してください。

### 接続のテスト

`Sync Evo` フォルダと、その中の保管庫のフォルダがあるかを問い合わせます。

### ダウンロード

- `Sync Evo` フォルダと保管庫のフォルダがあるか、それぞれ1つだけかを問い合わせます。
- 前回の同期の後に、Google Drive で何が変わったか（変更）を問い合わせます。使うのは、保管庫のフォルダの中の物だけです。
- 初回、保管庫の中のフォルダが変わった時、前回の同期からの変更を Google が返さない時は、ファイルの一覧すべてを問い合わせます。
- 新しいファイルと変わったファイルの、それぞれの中身を問い合わせます。

### アップロード

- ほかのデバイスの変更を上書きしないよう、ダウンロードの後に何が変わったかを問い合わせます。
- 足したファイルと変えたファイルの、それぞれの中身と名前を送り、要るフォルダを作ります。5 MB を超えるファイルは、再開可能なアップロードで送ります。
- 削除したファイルを、Drive のゴミ箱に入れます。
- その後、何が変わったかを、また問い合わせます。

### Google Drive からファイルを削除する

- Google Drive の `.gitignore` がデバイスの物と違う時は、保管庫の `.gitignore` を送ります。
- その後、削除するファイルを Drive のゴミ箱に入れます。

## ライセンスキー

有料化を始めた後、Dropbox か Google Drive で入れたライセンスキーは、キーを売っている Dodo Payments（`live.dodopayments.com`）に問い合わせて確かめます。Sync Evo が使うのは、Dodo のキー用の公開の API で、開発者のアカウントもシークレットも要りません。付けるのは、

- キー、
- 初回は、このデバイスのアクティベーションの名前として、設定のデバイス名、
- その後は、そのアクティベーションの ID

です。

保管庫の物も、Dropbox や Google のアカウントのことも、送りません。Dodo には、どのサービスでもそうであるように、通信の送り元のアドレスが見えます。Sync Evo の発行元である GYAP は、Dodo で、キーのアクティベーションとその名前を見られます。

- **キーを入れる**と、このデバイスでキーをアクティベートします。Sync Evo のキーでないと分かったキーは、すぐにまた手放します。
- **また確かめる。** 使えるキーは、Dropbox か Google Drive で同期した時か、設定画面を開いた時に、1日に1回また確かめます。Dodo につながらなかった時は、1時間後にもう一度試します。使えていたキーは、答えが無くても14日のあいだ使えます。Dodo が受け付けなくなったキーは、1日に1回問い合わせます。
- **キーを空にする**か、別のキーを入れると、このデバイスのアクティベーションを終えます。

有料化を始めるまでと、GitHub では、Sync Evo は Dodo Payments に接続しません。

## 保存する場所

- 設定と、何を同期したかの記録は、デバイスの保管庫の外（アプリのローカルストレージと IndexedDB）に置きます。同期しません。
- GitHub のトークンは、Obsidian のキーチェーンに保存します。設定に入るのは、保存した時の名前だけです。
- Dropbox では、Sync Evo が Dropbox につながるための物（リフレッシュトークン）を、アプリのローカルストレージに、このデバイスのこの保管庫の分として保存します。
- 設定には、Dropbox のアカウントの ID とメールアドレスが入ります。
- Google Drive では、リフレッシュトークンを同じように、アプリのローカルストレージに、このデバイスのこの保管庫の分として保存します。設定には、Google アカウントの ID とメールアドレス、Google Drive の保管庫のフォルダの ID が入ります。
- ライセンスキーと、Dodo が最後にそのキーについて返した答えは、アプリのローカルストレージに、どの保管庫で入れたかによらず、デバイスに1つ保存します。
- Sync Evo を削除しても、これらはデバイスに残ります。Dropbox か Google Drive では、先に**接続を解除**を押して、トークンを消してください。
- Sync Evo は `data.json` を書きません。
- Sync Evo は、自身のフォルダを同期しません。
