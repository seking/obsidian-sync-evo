# Sync Evo とほかの同期の手段

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/compared.md)

保管庫を同期する手段には、よい物がたくさんあります。このページでは、よく使われる手段と Sync Evo の違いと、ほかの手段の方が合う場合を書きます。ほかの手段については、2026年10月に、それぞれのページで確かめた内容です。その後に変わっているかもしれません。

## 並べて比べる

| | Sync Evo | Obsidian Sync | Obsidian Git | Remotely Save | Self-hosted LiveSync | Fit |
| --- | --- | --- | --- | --- | --- | --- |
| ノートを置く所 | 自分の GitHub・Dropbox・Google Drive | Obsidian のサーバー | 自分の Git のリポジトリ | 自分の S3・Dropbox・OneDrive・WebDAV など | 自分の CouchDB か、S3 互換のストレージ | 自分の GitHub |
| デバイスに要る物 | プラグインだけ | Obsidian のアカウントだけ | パソコンでは Git | プラグインだけ | サーバーを用意した後は、プラグインだけ | プラグインだけ |
| スマートフォン | 使えます | 使えます | README は、モバイルはとても不安定だとし、勧めていません | 使えます | 使えます | 使えます |
| 2台のデバイスで変えたノート | 統合するか、両方を残します（Google Drive は両方を残します） | ノートは統合します。ほかのファイルは新しい方が残ります | Git が統合します。競合は手で解きます | 新しい方か大きい方を選びます。小さなノートの統合と、両方を残す事は、有料の機能です | 統合するか、自分で選びます | 両方を残します。もう一方は `_fit/` に入ります |
| エンドツーエンドの暗号化 | ありません | あります | ありません | 選べます | 選べます | ありません |
| 料金 | [料金](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#料金)を見てください | 年払いで月 $4 から | 無料 | 無料。一部のサービスと機能は有料のプラン | 無料。サーバーの費用は別 | 無料 |

## ほかの手段の方が合う場合

- **ノートをエンドツーエンドで暗号化したい**：Obsidian Sync、Remotely Save、Self-hosted LiveSync。Sync Evo は暗号化しません。GitHub・Dropbox・Google Drive の中のノートは、そこにあるほかのファイルと同じように読めます。
- **変更を数秒でほかのデバイスに出したい**：Obsidian Sync か Self-hosted LiveSync。Sync Evo が同期するのは、操作した時と、オンにすれば、起動した時と数分おきです。
- **Obsidian の作り手の公式のサポートを、セットアップなしで受けたい**：Obsidian Sync。
- **ノートを S3・OneDrive・WebDAV に置きたい**：Remotely Save。Sync Evo が使えるのは、GitHub・Dropbox・Google Drive だけです。
- **パソコンだけを使い、Git が分かる**：Obsidian Git か、Git そのもの。ブランチ、自分で書くコミットの説明、どのホストでも、Git のすべてが使えます。同じリポジトリを、スマートフォンからは Sync Evo で使うこともできます（[デバイスを Git から Sync Evo に移す](faq.md#デバイスを-git-から-sync-evo-に移す)）。
- **デバイスがみな同じネットワークにある、またはみな Apple の物**：Syncthing や iCloud Drive で足りるかもしれません。
- **今の同期の仕方でうまくいっている**：そのまま使ってください。

## Sync Evo が合うかもしれない場合

- **スマートフォンを、Git を入れずに GitHub と同期したい。** Sync Evo は GitHub の API とやり取りします。デバイスには、clone して大きくなったり壊れたりするリポジトリがありません。
- **保管庫が大きい。** 数千ファイルの最初のダウンロードは、止まった所から続きます。GitHub では、10万ファイルまでのリポジトリを同期できます。38 MB までのファイルを同期します。[制限](limits.md)を見てください。
- **同期でノートを上書きされたくない。** 2台のデバイスで変えたノートは、統合するか両方を残します。多くのファイルを削除する前には、止まって確かめます。[ノートを失わないしくみ](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#ノートを失わないしくみ)を見てください。
- **セットアップより、ログインで済ませたい。** Dropbox と Google Drive では、リポジトリもトークンもサーバーも作りません。
- **変更の履歴をすべて残したい。** GitHub では、アップロードのたびにコミットになります。

## ほかの手段から移る

1台のデバイスでは、1つの保管庫を1つの手段だけで同期します。2つを同時に使うと、互いの変更を競合としてアップロードしたり、一方が削除した物を戻したりします。

1. これまでの手段で、すべてのデバイスを最後にもう一度同期し、そろえます。
2. 各デバイスで、これまでの手段をオフにします。Obsidian Sync は「設定 → 同期」、プラグインは「設定 → コミュニティプラグイン」、Obsidian の外のアプリはそのアプリで止めます。
3. 1台めで Sync Evo をセットアップし、同期します。新しく用意したリポジトリやフォルダは空なので、すべてをアップロードします。先に確かめるのは、公開の GitHub のリポジトリの時だけです。
4. ほかのデバイスでも Sync Evo をセットアップし、同期します。1台めがアップロードした物と同じファイルは、そのまま使います。違うファイルがあれば、先に確かめた上で両方を残し、デバイスの版は `_conflicts/` に入れます（保管庫の設定フォルダの中のファイルは `.trash/` に入れます）。

Git からは、[デバイスを Git から Sync Evo に移す](faq.md#デバイスを-git-から-sync-evo-に移す)を見てください。
