# Dropbox

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/dropbox.md)

設定の「接続」の**サービス**で、GitHub・Dropbox・Google Drive から選びます。

## フォルダ

- Sync Evo が使えるのは、Dropbox の中の Sync Evo 自身のフォルダ `Apps/Sync Evo/` だけです。
- `Apps` の名前は、Dropbox の言語に従います。日本語では「アプリ」で、Sync Evo の画面でも「アプリ/Sync Evo」と出ます。
- 保管庫は、そこにそれぞれのフォルダを持ちます。フォルダの名前は、設定の**フォルダ**で決めます。最初は、保管庫の名前です。

## セットアップ

1. **サービス**を**Dropbox**にします。
2. **フォルダ**の名前を確かめます。
3. **デバイス名**を確かめます。競合ファイルの名前に使います。
4. **接続する**を押し、ブラウザで許可します。
5. 「接続のテスト」の**テスト**を押し、**同期する**を実行します。

## 接続

- 接続は、ブラウザで行います。
- **接続する**を押し、求められたら Dropbox にログインして、**許可**を押します。ブラウザから Obsidian に戻ります。
- コピーするトークンはありません。
- **接続を解除**は、接続を忘れるよう Dropbox に伝え、デバイスでも忘れます。
- アカウント（ID とメールアドレス）は、設定に残ります。そのため、同じアカウントに接続し直しても、同期を最初からやり直しません。

## GitHub との違い

**アップロードは、コミットになりません。**

- ファイルは、まとめて送ります。
- 各ファイルを送るのは、このデバイスが最後に見たバージョンを、Dropbox がまだ持っている時だけです。
- ほかのデバイスが先に変えたファイルは、上書きしません。ほかのデバイスが変えたファイルは、削除しません。アップロードは残りを送り、そのことを知らせます。次のダウンロードで、そのファイルを競合として扱います。
- ファイルを送った後に中止したアップロードは、送ったファイルを Dropbox に残します。次の同期で、残りを送ります。

**削除したファイル**は、しばらく Dropbox のバージョン履歴に残ります（無料プランで30日）。Sync Evo のゴミ箱には入れません。

**自動の統合**では、前回の同期の時のファイルの内容を、Dropbox にあるバージョンから探します。見るのは、最新の100バージョンだけです。そのバージョンが無くなっているか、それより古い時は、代わりに競合ファイルとして両方を残します。

**大文字と小文字。** Dropbox は、大文字と小文字を区別しません。

- 保管庫の、大文字と小文字だけが違うパスの2つのファイルは、アップロードしません。
- Dropbox で大文字と小文字だけを変えた名前の変更は、フォルダの一覧を全部取り直した時にだけ、デバイスに届きます。
- 大文字と小文字だけが違うパスは、どのサービスでも同期しません。[比較](choosing-a-service.md)を見てください。

## 複数のデバイス

- 保管庫を同期するどのデバイスも、同じ Dropbox のアカウントに接続し、同じフォルダの名前にする必要があります。
- サービス、フォルダ、アカウントを変えると、最初のダウンロードと同じように、同期を最初からやり直します。

## 無料の期間とライセンスキー

Dropbox での Sync Evo は、今は無料です。いずれ有料になる可能性があり、その時は、3か月は無料で、その後はライセンスキーが要ります。有料化は、始める前に知らせます。[料金](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#料金)を見てください。

始めた後は、

- 3か月は、保管庫ごとではなく、Dropbox のアカウントごとに数えます。有料化を始めた日より前から数えることはありません。
- 3か月は、`Apps/Sync Evo/` の一番上、保管庫のフォルダの隣にある、Sync Evo 自身の小さなファイル `.sync-evo-since` から数えます。Sync Evo は、有料化を始めた後、そのアカウントで最初に同期した時に、このファイルを置きます。3か月は、その日から数えます。そのアカウントに接続するどのデバイスも、このファイルに従います。消さずに置いておいてください。
- その3か月が終わった後や、終わる間際に、デバイスで Sync Evo を使い始めた時も、そのデバイスでは、その日から14日は無料です。終わる前に知らせるためです。
- キーは、設定の**ライセンスキー**に、デバイスごとに入れます。[ライセンスキー](settings.md#ライセンスキー)を見てください。
