# よくある質問

[English](https://github.com/seking/obsidian-sync-evo/blob/main/docs/faq.md)

## Sync Evo は無料ですか？

今は、どのサービスでも無料です。Dropbox と Google Drive は、いずれ有料になる可能性があり、その時はライセンスキーが要ります。キーは月 $3・年 $24・買い切り $49 で、1つのキーで両方を使えます。有料化は、README とリリースノートで知らせてから始めます。始めた後も、始めた日か、そのアカウントで最初に同期した日の遅い方から3か月は無料です。[料金](https://github.com/seking/obsidian-sync-evo/blob/main/README.ja.md#料金)を見てください。

## 無料の期間が終わると、どうなりますか？

有料化を始めた後の話です。30日のあいだ、Sync Evo は Dropbox や Google Drive からダウンロードだけを行い、何もアップロードしません。その後は、それらとの同期を止めます。何も削除しません。また同期するには、設定でライセンスキーを入れるか、今は無料の GitHub に保管庫を移してください。[ライセンスキー](settings.md#ライセンスキー)を見てください。

## デバイスごとにキーが要りますか？

いいえ。1つのキーを、Dropbox と Google Drive で、自分のデバイス5台まで使えます。キーは、各デバイスの設定で入れます。どの保管庫で入れても、デバイスごとに一度アクティベートします。

ほかのデバイスのために空きを作るには、要らなくなったデバイスで、キーの欄を空にします。そのデバイスのアクティベーションが終わります。そのデバイスがもう無い時は、Dodo Payments の[請求ポータル](https://customer.dodopayments.com/login/bus_0NpvnyuwMvGA62iaE3swK)で、そのデバイスのアクティベーションを外してください（デバイス名で並びます）。contact@gyap.jp へのご連絡でも外せます。

## サブスクリプションを解約するには？

Dodo Payments の[請求ポータル](https://customer.dodopayments.com/login/bus_0NpvnyuwMvGA62iaE3swK)で解約できます。キーを買った時のメールアドレスを入れ、届いたリンクを開いて、サブスクリプションを選びます。次の請求日に解約すると、払った期間の終わりまでキーを使えます。今すぐ解約すると、キーはすぐに使えなくなり、残りの期間の分は返金しません（下の14日以内の返金は別です）。contact@gyap.jp へのご連絡でも解約できます。

## 返金はできますか？

最初の購入と、サブスクリプションの更新のそれぞれから14日以内なら、理由を問わず全額を返金します。返金は Dodo Payments を通して行います。返金したキーは、使えなくなります。[利用規約](https://gyap.jp/sync-evo/terms)を見てください。

## 統合したファイルの前の内容は、どう戻しますか？

Sync Evo は、それを保管庫の `.trash/.sync-evo-merged/` に、`<date> <name>.<extension>` という名前で残します。このフォルダは、Obsidian に表示されません。デバイスのファイル管理のアプリで、写しを Obsidian に表示されるフォルダへ移してください。[統合したファイルの前の内容を戻す](syncing.md#統合したファイルの前の内容を戻す)を見てください。

## 競合ファイルはどこにありますか？

保管庫のルートの `_conflicts/` フォルダに、`<date> <name> (<device>).<extension>` という名前であります。同期の知らせに、その名前が出ます。`_conflicts/` の外へ移すか名前を変えない限り、30日後に `.trash/` へ移します。[競合ファイル](syncing.md#競合ファイル)を見てください。

## デバイスを Git から Sync Evo に移す

1台のデバイスでは、Git（または Obsidian Git プラグイン）か Sync Evo のどちらかだけを使ってください。Sync Evo が同期した内容は、Git からはまだコミットしていない変更に見えるため、そのデバイスでは pull が止まったり、コミットに混ざったりします。ほかのデバイスは、同じリポジトリで Git を使い続けられます。

デバイスを Sync Evo に移すには（スマートフォンで自動同期をするため、など）、

1. そのデバイスで、Git ですべてをコミットして push し、その後 pull して、リポジトリと合わせます。
2. そのデバイスで、Obsidian Git プラグインを無効にするか、Git のアプリを止めます。
3. Sync Evo をセットアップして、同期します。リポジトリと合っているファイルは、そのまま使います。

デバイスがリポジトリより遅れていると、その後に変わったファイルは、最初の同期ですべて両方が残り、デバイスの物が `_conflicts/` に入ります。手順 1 が大事なのは、このためです。

保管庫のルートに `.git` フォルダがある間は、それを見つけたことを Sync Evo が一度知らせ、同期は続けます。そのデバイスで Git を使わなくなったら、そのフォルダを削除してください。

## iCloud Drive の保管庫を使えますか？

使えますが、対応は試験的です。同じ iCloud の保管庫を、2台のデバイスの Sync Evo で同期しないでください。Mac で、git の作業ツリーにしないでください。選べるなら、「このiPhone内」の保管庫の方が簡単です。[iCloud Drive の保管庫](icloud.md)を見てください。

## 何かを除外すると、どうなりますか？

デバイスでもサービスでも、何も削除しません。除外した物はアップロードもダウンロードもせず、どちらかで削除しても、もう片方には反映しません。除外しているファイルをサービスから削除するには、設定で「GitHub から削除」（または Dropbox、Google Drive）を使います。[除外した時に起きること](settings.md#除外した時に起きること)を見てください。

## Google Drive のフォルダにファイルを入れました。なぜ同期されないのですか？

Google Drive で Sync Evo から見えるのは、Sync Evo が自分で作ったファイルだけです。Google Drive の Web サイトや パソコン版 Google ドライブ で足したファイルは、見えません。代わりに、どれかのデバイスで保管庫にファイルを入れてください。[Sync Evo から見える物](google-drive.md#sync-evo-から見える物)を見てください。

## 仕事や学校のアカウントで Google Drive に接続できません

Google Workspace のアカウントでは、管理者が Sync Evo のようなアプリを止めていることがあります。管理者に尋ねるか、別の Google アカウントを使ってください。

## Google が Sync Evo の接続を受け付けなくなったと出ます

Google アカウントで Sync Evo を外したか、ほかの理由でこのデバイスの接続が切れました。1つの Google アカウントが残す Sync Evo の接続は100までで、それを超えると一番古い物が切れます。設定で、もう一度**接続する**を押してください。同じアカウントなら、同期は前の続きから進みます。[接続を解除する](google-drive.md#接続を解除する)を見てください。

## Google Drive にフォルダが複数あると出ます

1つだけを残してください。もう1つを Google Drive でゴミ箱に入れて、どのデバイスでも、もう一度同期します。[フォルダが前と違う時](google-drive.md#フォルダが前と違う時)を見てください。

## Sync Evo を前のバージョンに戻すには？

> [!WARNING]
> 戻すデバイスで、同期を最後まで終えてから戻してください。途中で止まった同期のまま戻さないでください。

統合の途中で止まった同期は、次の同期が仕上げます。前のバージョンはそれを知らず、統合したノートをサービスの内容で上書きすることがあります。その時、元のノートは `.trash/.sync-evo-merged/` にしか残りません。全デバイスを戻すなら、それぞれのデバイスで同じようにしてください。

戻せるのは、[リリースのページ](https://github.com/seking/obsidian-sync-evo/releases)にあるバージョンです。そこに無いバージョンは入れられません。

BRAT でインストールした時：

1. 設定 → BRAT で、Sync Evo の戻したいバージョンを選びます。
2. そこで選べない時は、ベータプラグインの一覧から Sync Evo を外します。次に**Add beta plugin**を押し、`https://github.com/seking/obsidian-sync-evo` を入力して、最新の代わりにそのバージョンを選びます。
3. 設定 → コミュニティプラグインで Sync Evo をオフにしてからオンにするか、Obsidian を再起動します。

コミュニティプラグインの一覧からインストールした時：

1. リリースのページで戻したいバージョンを開き、`main.js`・`manifest.json`・`styles.css` をダウンロードします。
2. 保管庫の `.obsidian/plugins/sync-evo/` のフォルダに、今あるファイルと置き換えて入れます。このフォルダは隠れています。Mac では、Finder で `⌘⇧.` を押すと見えます。Android では、ファイル管理のアプリのメニューで「隠しファイルを表示」を選びます。iPhone と iPad の「ファイル」アプリには出ないので、BRAT を使ってください。
3. Obsidian を再起動します。そのバージョンのままにしたい間は、Sync Evo の**更新**を押さないでください。

Dropbox にした保管庫には Sync Evo 0.4.0 以降が、Google Drive にした保管庫には 0.5.0 以降が要ります。それより前のバージョンは、その保管庫を同期せず、設定もそのままにします。

## バグはどう報告しますか？

[issue](https://github.com/seking/obsidian-sync-evo/issues) を開き、**Bug report** を選んでください。バージョン、デバイス、サービス、手順、同期ログを尋ねます。同期ログは、**Sync Evo: 同期ログを表示**を実行して、**すべてコピー**を押すと写せます。日本語で書いて構いません。

報告にトークンを書かないでください。同期ログにはファイル名が入ります。人に見せたくない名前は、伏せてください。セキュリティの問題は issue にせず、[SECURITY.md](https://github.com/seking/obsidian-sync-evo/blob/main/SECURITY.md) を見てください。

## GitHub のトークンの期限が切れました。どうすればよいですか？

fine-grained のトークンは、作った時に決めた日で切れます。設定画面と README のリンクでは 90日ですが、ほかの日数を選んだかもしれません。その日を過ぎると、同期が「GitHub がトークンを受け付けませんでした」で失敗し、接続のテストも同じになります。デバイスでも GitHub でも、何も変わりません。

1. GitHub で [Fine-grained tokens](https://github.com/settings/personal-access-tokens) を開き、そのトークンを開いて **Regenerate token** を押します。リポジトリと権限はそのままで、新しい期限を選べます。Sync Evo の設定画面の**トークン**の下のリンクで、新しく作っても構いません。
2. 新しいトークンをコピーし、**トークン**で選んでいるシークレットの値として、前の値の代わりに保存します。新しいシークレットとして保存して、それを選んでも構いません。
3. **接続のテスト**の**テスト**を押してから、同期します。同期は前の続きから進みます。

デバイスごとに行ってください。トークンは、デバイスごとに保存されています。
