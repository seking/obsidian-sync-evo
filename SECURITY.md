# Security

## Reporting a vulnerability

Do not report a vulnerability in a public issue. Report it privately on GitHub instead:

1. Open the [Security tab](https://github.com/seking/obsidian-sync-evo/security) of this repository.
2. Press **Report a vulnerability**, and fill in the form.

Only you and the maintainer can see the report. You may write it in English or in Japanese.

What helps:

- the version of Sync Evo, the device and its OS,
- the service: GitHub, Dropbox or Google Drive,
- the steps that show the problem, and what someone could do with it.

Do not put a secret into the report: no token, password, license key or other value that gives access to an account, even one that has expired. Write `<token>` or the like in its place. If you think a secret of yours was exposed, revoke it first.

## Supported versions

Only the latest released version of Sync Evo gets security fixes. A fix comes as a new version. A problem you find in a beta may be reported the same way, and is fixed in the next release.

## What happens next

Sync Evo is maintained by one person. You will get a reply as soon as possible, but no set number of days is promised. Once a fix is released, the report may be published as a security advisory, with credit to you if you like.
